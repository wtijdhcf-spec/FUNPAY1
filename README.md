# 🤖 FunPay Bot (без демпинга)

Автоматический бот для площадки **FunPay**: поднимает ваши предложения, держит аккаунт в статусе «Онлайн» и (по желанию) отвечает покупателям в чате.

> ## ⛔ Изменение цен ОТКЛЮЧЕНО НАВСЕГДА
> Бот **не умеет менять цены** ваших лотов — ни автоматически, ни по кнопке, ни через API.
> Это финальное решение владельца: цены меняются ТОЛЬКО вручную на самом FunPay.
> Метод отправки запроса на смену цены заблокирован флагом `PRICE_EDITS_ENABLED = False`
> в `funpay_api.py`, кнопок цен в панели нет, а тесты (`test_fixes.py`) следят,
> чтобы ни один файл проекта не мог вызвать смену цены. Флаг не включать.

> ## 📋 Шаблоны лотов (переживают выход из аккаунта)
> Вкладка «Шаблоны»: лот сохраняется кнопкой 📥 во вкладке «Мои лоты»
> (забирает название, цены, описания RU/EN, автовыдачу и секреты 1-в-1)
> или кнопкой «Сохранить заполненную форму». Шаблоны лежат в `saved_lots.json`
> на диске — выход из аккаунта / смена ключа их НЕ стирает.
> Кнопка «▶ Выставить» подставляет шаблон в форму создания — выбери разделы и жми «Выставить».

> ## 🤖 ИИ-генератор лота (текст)
> На вкладке «Создать лоты»: идея заголовка + ключевые особенности + **стиль-эмодзи**
> (например 🟦🟥🟩🟧) — генератор собирает краткое описание, подробное описание и
> (по галочке) сообщение для покупателя в этом стиле, автоматически переводит на английский.
> Кнопки «✨ Улучшить» причёсывают текст, «🌐 → EN» переводят отдельное поле.
> Перевод бесплатный, без API-ключей (Google gtx + MyMemory как запасной).

> ## 🚪 Кнопка «Выйти из аккаунта»
> В шапке панели есть кнопка, которая останавливает бота, закрывает сессию
> на стороне FunPay (`/account/logout`) и стирает `golden_key` из `config.json`.
> После этого ключ не работает нигде — чтобы войти снова, нужен новый ключ.

> ## ⏸ Бот не заходит в аккаунт сам
> По умолчанию `settings.autostart = false`. Запуск `start.bat` поднимает
> только панель; в FunPay бот не заходит, пока вы не нажмёте «▶ Старт».

## ⚡ Что осталось в работе

1. **Автоподнятие лотов** — нажимает «Поднять предложения» во всех ваших
   разделах (`lots` + `chips`) с кулдаунами и случайным джиттером.
2. **Вечный онлайн** — фоновые heartbeat-запросы к FunPay, чтобы аккаунт
   светился покупателям с фильтром «Только онлайн».
3. **Авто-ответчик (сообщения покупателям)** — без главного тумблера: пока
   запущен бот, работают включённые тумблеры сообщений:
   👋 авто-приветствие новых покупателей в чатах («только совсем новые чаты»,
   «не приветствовать при системных сообщениях»), 🛒 ответ на новый заказ,
   ✅ ответ при подтверждении, ⭐ ответ на отзыв и 🤖 автоответы по ключевым
   словам (точное совпадение / содержит). Старые заказы и чаты подхватываются
   тихо — сообщений задним числом нет.
4. **Мониторинг без вмешательства** — бот видит ваши лоты, но не трогает их цены.
5. **Ручные инструменты в панели** — создание лотов (с ИИ-генератором текста),
   шаблоны лотов, поиск/удаление дубликатов, снятие и возврат лотов.
6. **Уведомления в Telegram** — отключены по умолчанию, включаются в настройках.
7. **Фоновый цикл** — проверка каждые 2–5 минут (настраивается), подробный
   лог в консоли и в `bot.log`.

> ## 🚄 Почему панель теперь не «виснет»
> - `/api/status` — проверка ключа кэшируется на 60 сек (было: полный
>   anti-detect цикл при каждом открытии панели).
> - `/api/lots` — кэш 30 сек, повторные клики не бьют FunPay (меньше 429/CAPTCHA),
>   а при ошибке показывается причина и кнопка «↻ Повторить», а не красная абракадабра.
> - Игры — кэш 1 час; если FunPay заблокировал запрос, панель пишет это словами.

```text
funpay_undercut_bot/
├── config.json          # Основной файл конфигурации

```

## 🛠 Пошаговая настройка

### Шаг 1: Получение `golden_key` (Cookie FunPay)
1. Откройте сайт [funpay.com](https://funpay.com) в браузере и войдите в свой аккаунт.
2. Нажмите клавишу **F12** на клавиатуре (откроется панель разработчика).
3. Перейдите во вкладку **Application** (или **Хранилище** в Firefox) $\rightarrow$ слева выберите раздел **Cookies** $\rightarrow$ `https://funpay.com`.
4. Найдите строку с именем **`golden_key`** и скопируйте ее значение (длинная строка из букв и цифр).

### Шаг 2: Создание Telegram бота (по желанию)
1. Откройте Telegram и напишите боту [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`, укажите имя и username для бота. Скопируйте полученный **API Token**.
3. Чтобы узнать свой **Chat ID**, напишите боту [@userinfobot](https://t.me/userinfobot) (он пришлет ваш `Id`).
4. Нажмите `/start` в созданном вами боте, чтобы он мог присылать вам сообщения.

### Шаг 3: Заполнение `config.json`
Откройте файл `config.json` в любом текстовом редакторе (Блокнот, VS Code) и внесите ваши данные:

```json
{
  "golden_key": "СЮДА_ВСТАВЬТЕ_ВАШ_GOLDEN_KEY",
  "telegram": {
    "enabled": true,
    "bot_token": "1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ",
    "chat_id": "123456789"
  },
  "settings": {
    "check_interval_seconds": 120,
    "only_online_sellers": true,
    "min_price_safety_floor": 0.01,
    "undercut_rules": {
      "threshold_rub": 1.0,
      "step_high": 0.1,
      "step_low": 0.01
    },
    "match_parameters": {
      "match_server": true,
      "match_side": true,
      "match_subcategory": true,
      "match_keywords": true
    },
    "auto_detect_all_user_lots": true
  },
  "custom_lot_rules": {
    "12345678": {
      "enabled": true,
      "keywords": ["VIP", "Global"],
      "exclude_keywords": ["Аренда"],
      "min_price": 50.0,
      "custom_step": 0.5
    }
  }
}
```

> **Совет по `custom_lot_rules`:**  
> Если для какого-то конкретного лота вы хотите задать индивидуальные минимальные цены (`min_price`), обязательные ключевые слова (`keywords`) или исключающие слова (`exclude_keywords`), добавьте его ID (номер лота) в секцию `custom_lot_rules`.

## 🚀 Запуск бота

### Вариант 1: Запуск на Windows (Локально)
Просто дважды кликните по файлу **`start_windows.bat`**.  
Скрипт автоматически создаст виртуальное окружение, установит зависимости и запустит бота.

Или через командную строку / PowerShell:
```powershell
cd funpay_undercut_bot
pip install -r requirements.txt
python main.py
```

---

### Вариант 2: Запуск на Linux / VPS (Хостинг)

#### Способ А: Через обычный скрипт / screen (24/7)
```bash
cd funpay_undercut_bot
chmod +x start_linux.sh

# Запуск в фоновой сессии screen (чтобы работал при закрытии консоли)
screen -S funpay_bot
./start_linux.sh
```
*(Для выхода из screen нажмите `Ctrl + A`, затем `D`. Чтобы вернуться обратно: `screen -r funpay_bot`)*

#### Способ Б: Через Docker / Docker Compose (Рекомендуется)
```bash
cd funpay_undercut_bot
docker compose up -d --build
```
Просмотр логов контейнера:
```bash
docker compose logs -f
```
